# Nova Store — GA4 + GTM Practice Website

این سایت فقط برای تمرین Google Analytics 4 و Google Tag Manager ساخته شده است.

## فایل‌ها
- index.html — صفحه اصلی
- product.html — صفحه جزئیات محصول
- style.css — ظاهر سایت

## رویدادهای آماده
- site_ready
- hero_cta_click
- view_item
- add_to_cart
- generate_lead
- outbound_click (با GTM قابل ساختن است)
- scroll (با GTM قابل ساختن است)

## شروع سریع
1. فایل index.html را با Chrome باز کن.
2. روی محصولات، دکمه‌ها و فرم کلیک کن.
3. در مرحله بعد GTM و GA4 را به سایت متصل کن.
4. در GTM از Preview برای تست استفاده کن.

نکته: فعلاً هیچ شناسه GTM یا GA4 داخل فایل قرار داده نشده؛ این کار را عمداً گذاشته‌ایم تا اتصال را خودت به‌عنوان تمرین انجام بدهی.
